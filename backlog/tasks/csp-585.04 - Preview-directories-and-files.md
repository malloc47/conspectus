## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
- Why: ADR 0112 §1–2. Workspaces, the listing half of a checkout's preview, and every path-valued field (`cwd`, `root`, `common_dir`, `git_dir`, `state_scope`, `active_pane_current_path`, `source_paths`, pin `store`) should show what is at that path.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 A Workspace node previews a listing of its root
- [x] #2 A directory-valued field row previews a listing of that directory
- [x] #3 A file-valued field row (pin `store`) previews the file's contents, capped in size with a note when cut
- [x] #4 A path that no longer exists previews "no longer exists" instead of an error (ADR 0111)
- [x] #5 Listings never follow symlinks out of the listed directory or write anything (ADR 0087)
<!-- AC:END -->

## Definition of Done
<!-- DOD:BEGIN -->
- [x] #1 `just check` passes, or `git diff --check` for docs-only changes
- [x] #2 Docs and ADRs are updated when behavior, architecture, or workflow change
<!-- DOD:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Give each `CoreField` its raw value typed for its preview (`FieldValue::Path`), set where path fields are built.
2. Resolve a field row with a typed value to a `Path` source; a Workspace node to a `Path` source for its root.
3. Load paths on the preview worker: a capped, sorted listing that never follows symlinks, or capped file contents; "no longer exists" when missing.
4. Render loaded lines top-anchored; keep listings visible under `--no-live-preview`.
5. Unit tests for the loader and resolver; live snapshot check.
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
- One `Path` value type covers directories and files: the loader checks what is at the path, so `state_scope` (a directory for Claude Code and Codex, a database file for opencode) previews correctly either way.
- `source_paths` previews its first path, matching the field's displayed value.
- Listings and file contents stay visible under `--no-live-preview`, per ADR 0112 §6.
- Caps: 500 listed entries (5,000 read), 64 KiB of a file; binary files show their size.
<!-- SECTION:NOTES:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Path-valued field rows (`cwd`, `root`, `common_dir`, `git_dir`, `state_scope`, `active_pane_current_path`, `source_paths`, pin `store`) preview a directory listing or a file's capped contents, a Workspace lists its root, and a missing path previews "no longer exists". Listings never follow symlinks and read only. Fields now carry typed raw values (`FieldValue`) for later value types to extend. Verified with `just check` (2,256 tests, including loader tests for listings, symlinks, missing paths, large and binary files) and a live snapshot of a session's `cwd` row.
<!-- SECTION:FINAL_SUMMARY:END -->
