## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
- Why: ADR 0112 §1–2. Workspaces, the listing half of a checkout's preview, and every path-valued field (`cwd`, `root`, `common_dir`, `git_dir`, `state_scope`, `active_pane_current_path`, `source_paths`, pin `store`) should show what is at that path.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A Workspace node previews a listing of its root
- [ ] #2 A directory-valued field row previews a listing of that directory
- [ ] #3 A file-valued field row (pin `store`) previews the file's contents, capped in size with a note when cut
- [ ] #4 A path that no longer exists previews "no longer exists" instead of an error (ADR 0111)
- [ ] #5 Listings never follow symlinks out of the listed directory or write anything (ADR 0087)
<!-- AC:END -->

## Definition of Done
<!-- DOD:BEGIN -->

- [ ] #2 Docs and ADRs are updated when behavior, architecture, or workflow change
