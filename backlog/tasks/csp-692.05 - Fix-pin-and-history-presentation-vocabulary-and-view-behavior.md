## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Gone muxes in the Mux view don't align with live ones, an unstarted pin has no distinct marker (the word gone describes the entity, not the pin), the interface says slot where the operator sees a pin, ADR numbers appear in the TUI, agent and binary names are plain text with a dot delimiter in the Pinned and History views instead of the highlighted chip other views use, sessions rows lack the agent glyph, History cannot hide pinned records, the right pane stays highlighted when unfocused, and regrouping keeps the old scroll position.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Gone mux rows align with live mux rows column for column
- [ ] #2 A pin with no target yet shows a hollow pin glyph in the ghost color, and its status word no longer reads gone
- [ ] #3 The interface says pin for the thing the operator selects, and never slot
- [ ] #4 No ADR number, backlog ID, or design-document name appears in any TUI text, and CLAUDE.md states the rule
- [ ] #5 The Pinned and History views show the agent or binary as the same highlighted chip other views use, without the dot delimiter
- [ ] #6 Sessions rows show the agent glyph
- [ ] #7 History has an unpinned only filter, checked by default
- [ ] #8 An unfocused pane shows no highlighted row, in both panes
- [ ] #9 Regrouping any view scrolls to the top
<!-- AC:END -->
