## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
A stopped, unpinned mux that appears in History also appears in the Mux view. Stopped muxes belong in History; the Mux view should show running muxes, plus stopped muxes that a pin points at. This changes the earlier default of showing every ghost.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The Mux view shows stopped muxes only when a pin points at them, by default
- [ ] #2 A Controls option shows all stopped muxes, off by default, and the header still counts stopped muxes
- [ ] #3 Operator docs and the design describe the new default
