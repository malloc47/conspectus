## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The operator wants a content query to act as a filter on the session list, not only as a results list. One app-wide query, held in memory only (never persisted, never in the snapshot or sent to the daemon), narrows Sessions, Mux, and PRs to sessions whose transcripts match, composes with the existing filters and grouping, shows its hit counts and progress, and is cleared with the other filters. It departs deliberately from ADR 0031's per-view, persisted, no-free-text filter rules; the ADR in CSP-616.01 amends it.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
