## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
- Why: ADR 0112 §1–2. A checkout's working-tree state, a repo's history, and a branch's position relative to its upstream are what the operator usually wants when selecting them.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A Checkout previews `git status --short` above a listing of its root
- [ ] #2 A Repo previews recent commits on its default branch and its remotes
- [ ] #3 A Branch previews recent commits at its ref and its ahead/behind counts against its upstream, when it has one
- [ ] #4 Ref fields (`refname`, `upstream`) preview recent commits at the ref; `current_commit` previews `git show --stat`
- [ ] #5 Every git call is a read-only `git -C <path>` command, and a missing checkout or ref previews a clear unavailable state
<!-- AC:END -->

## Definition of Done
<!-- DOD:BEGIN -->
- [ ] #1 `just check` passes, or `git diff --check` for docs-only changes
- [ ] #2 Docs and ADRs are updated when behavior, architecture, or workflow change
