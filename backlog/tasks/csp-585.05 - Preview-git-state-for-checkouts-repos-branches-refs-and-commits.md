## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
- Why: ADR 0112 §1–2. A checkout's working-tree state, a repo's history, and a branch's position relative to its upstream are what the operator usually wants when selecting them.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 A Checkout previews `git status --short` above a listing of its root
- [x] #2 A Repo previews recent commits on its default branch and its remotes
- [x] #3 A Branch previews recent commits at its ref and its ahead/behind counts against its upstream, when it has one
- [x] #4 Ref fields (`refname`, `upstream`) preview recent commits at the ref; `current_commit` previews `git show --stat`
- [x] #5 Every git call is a read-only `git -C <path>` command, and a missing checkout or ref previews a clear unavailable state
<!-- AC:END -->

## Definition of Done
<!-- DOD:BEGIN -->
- [x] #1 `just check` passes, or `git diff --check` for docs-only changes
- [x] #2 Docs and ADRs are updated when behavior, architecture, or workflow change
<!-- DOD:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. A `GitQuery` source (status, repo, log, show) loaded by a read-only git runner on the preview worker.
2. Node sources for Checkout, Repo, and Branch; `FieldValue::Ref` and `FieldValue::Commit` on branch fields.
3. Group rows fall back to their node's source.
4. Loader tests against a scratch repo (including that status leaves the index untouched) and resolver tests.
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
- `git status` can refresh and rewrite the index, which ADR 0087 forbids; every call passes `--no-optional-locks` and `GIT_OPTIONAL_LOCKS=0`, and a test checks the index's mtime is unchanged.
- "Default branch" is the local branch `origin/HEAD` names, the remote branch when there's no local one, else `HEAD`.
- Group rows (repo, checkout, workspace) in the left tree previously said "no preview for this row"; they now preview their node.
- The checkout's `current_branch` field names another node; it previews the branch with `CSP-585.09`'s node-valued fields.
<!-- SECTION:NOTES:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Checkouts preview `git status` above a listing of their root, repos their default branch's recent commits and remotes, branches their commits with ahead/behind against the upstream; `refname`/`upstream` fields preview commits at the ref and `current_commit` previews `git show --stat`. Every git call is read-only with optional locks off, and missing checkouts, repos, refs, or git preview a clear reason. Verified with `just check`, loader tests against a scratch repo, resolver tests, and live snapshots of this repo's group row and checkout.
<!-- SECTION:FINAL_SUMMARY:END -->
