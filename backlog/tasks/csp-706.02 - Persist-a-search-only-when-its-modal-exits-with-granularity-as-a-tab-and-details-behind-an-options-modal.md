## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
While the content modal is open the Search view should stay as it was; the search is recorded in the history only when the modal exits. Results granularity becomes a visible tab in the modal and is changeable from the Search view, replacing Ctrl-R. Whether thinking, tools and other kinds are searched moves into a separate options modal so the key list stays short.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The Search view does not change while the content modal is open; on any exit with a non-empty query the search becomes the newest history entry, and an empty or never-started search records nothing
- [ ] #2 Granularity is a visible Sessions/Messages tab in the content modal with a documented key, replaces Ctrl-R, and can be changed from the Search view and Controls without rescanning, applying to the displayed history entry
- [ ] #3 Tools, thinking, and the other content kinds are set in a search options modal with checkboxes (Space toggles, Enter applies, Esc cancels), opened from the content modal, the Search view, and Controls, and the key list no longer carries a key per kind
- [ ] #4 Docs, help, key tables, consistency tests, tui-columns, and the ADR are updated; the old message/flat modes map onto Sessions (rows expand to their messages) and Messages (flat, newest first), with config values kept working
<!-- AC:END -->
