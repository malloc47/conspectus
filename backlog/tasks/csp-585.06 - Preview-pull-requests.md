## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
- Why: ADR 0112 §1. A PR row shows only its identity today; its title, body, checks, and review state are what tell PRs apart. `CSP-171.01` builds the asynchronous `gh` fetch and cache this preview renders.

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. `GhRunner::view_pull_request` on the existing runner, with offline detection added to its failure classification.
2. A `PullRequest` preview source loaded on the preview worker: title, state, checks, reviews, body.
3. Unavailable states for missing, unauthenticated, or offline `gh`, non-GitHub PRs, and `CONSPECTUS_DISABLE_FORGE`.
4. Fake-`gh` tests for rendering and each unavailable reason; a real `gh pr view` run to validate the JSON fields.
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
- Built on the ADR 0112 preview mechanism instead of waiting for `CSP-171.01`: the preview worker, in-memory cache, in-flight guard, and `r` refresh are the async fetch-and-cache that task describes, so the dependency is removed. Notes on `CSP-171.01` record what this delivers for it.
- No PR row was available to snapshot live (only the sessions and mux views are reachable, and this repo has no open PRs); rendering is covered with fake `gh` output, and the `--json` field list was checked against a real `gh pr view`.
<!-- SECTION:NOTES:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
ForgePr nodes preview their title, state (draft, review decision), checks summary with failing and pending checks named, latest reviews, and body, read with `gh pr view` on the preview worker and held in memory only. Loading shows while `gh` runs; a missing, unauthenticated, or offline `gh` previews an unavailable state. Verified with `just check`, fake-`gh` tests for rendering and each unavailable reason, and a real `gh pr view` run validating the requested fields.
