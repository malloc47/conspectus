## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Search results can be one row per session, or a row per matching message nested under its session. The operator also wants every matching message as a single flat list across all sessions, newest first, without session grouping, as a third mode. The flat list is a mode of the same content search: it applies to the Search view, the / overlay, the conspectus search command, and the [search] config.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A third results mode lists every matching message across all sessions as one flat list ordered newest first, with the session shown on each row
- [ ] #2 The mode is selectable in the / overlay, the Search view's Controls, the [search] config group value, and the conspectus search --group flag, and cycles with the existing results key
- [ ] #3 Enter, v, the . menu, pin, and the other row actions on a flat row act on its session and open the viewer at that message
- [ ] #4 Memory stays bounded when many sessions match: the flat list loads message details up to a global cap and says when it is showing only the newest part
- [ ] #5 The ADR, operations guide, docs/tui-columns.md, and consistency tests cover the new mode
<!-- AC:END -->
