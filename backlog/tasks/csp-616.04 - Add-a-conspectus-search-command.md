## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Operators want to search session contents from scripts and pipelines as well as from the TUI (operator decision 2026-10-16). `conspectus search <query>` exposes the CSP-616.03 scanner with the same grouping and content-kind options as the TUI, defaulting to the `[search]` config.

Context:
- The session list comes from the same warm-start snapshot path as `table` and `graph` (daemon snapshot or local discovery). Transcripts are read in this process, never through the daemon (ADR 0086).
- Output follows `conspectus table` conventions: a width-aware table for people and JSON for scripts. Per-session rows show session, harness, hit count, latest hit, and snippet; per-message rows show session, turn, role, kind, time, and snippet.
- Decide the exit status when nothing matches (grep convention: 1) and record it in the help text.
<!-- SECTION:DESCRIPTION:END -->
