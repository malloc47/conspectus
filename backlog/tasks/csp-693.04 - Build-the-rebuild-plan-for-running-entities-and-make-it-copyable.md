## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Show rebuild plan says nothing useful for a running mux. The plan should be built as if the entity had stopped, from the command, working directory, and session Conspectus knows now, and it should list the exact commands so someone can recreate the state outside Conspectus and paste them into a shell.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 A plan can be built for a running mux, worktree, or repo under the assumption it stopped, labelled as hypothetical, from the live command, directory, harness, and last session
- [x] #2 Every step carries the exact shell command that would run, correctly quoted, including socket flags, resume arguments, wrapper commands, worktree switch, and clone
- [x] #3 The plan modal has a key that copies all commands as a pasteable script, and the CLI can print the same script
- [x] #4 The same plan text is used by rebuild --dry-run, with a flag to assume the entity stopped
<!-- AC:END -->

## Definition of Done
<!-- DOD:BEGIN -->
- [x] #1 `just check` passes, or `git diff --check` for docs-only changes
- [x] #2 Docs and ADRs are updated when behavior, architecture, or workflow change
<!-- DOD:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
rebuild --dry-run --assume-stopped plans running muxes, worktrees, repos, and sessions as if stopped, with exact shell-quoted commands built from the executors' own arguments; --script prints a pasteable script; the TUI plan viewer copies it with y. Verified by engine tests, real-tmux CLI tests, and a smoke check that pipes the script to sh.
