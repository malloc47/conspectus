## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Show rebuild plan says nothing useful for a running mux. The plan should be built as if the entity had stopped, from the command, working directory, and session Conspectus knows now, and it should list the exact commands so someone can recreate the state outside Conspectus and paste them into a shell.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A plan can be built for a running mux, worktree, or repo under the assumption it stopped, labelled as hypothetical, from the live command, directory, harness, and last session
- [ ] #2 Every step carries the exact shell command that would run, correctly quoted, including socket flags, resume arguments, wrapper commands, worktree switch, and clone
- [ ] #3 The plan modal has a key that copies all commands as a pasteable script, and the CLI can print the same script
- [ ] #4 The same plan text is used by rebuild --dry-run, with a flag to assume the entity stopped
<!-- AC:END -->

- [ ] #2 Docs and ADRs are updated when behavior, architecture, or workflow change
