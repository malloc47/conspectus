## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Ctrl+/ opens a wide content-search modal with a visible Current/All indicator toggled by Tab, and terminals that send Ctrl+/ as another byte are handled, with a documented fallback key
- [ ] #2 Every content search is kept as the latest entry in the Search view; Ctrl+S from the modal jumps to the view; the last N searches are kept in memory and can be paged in the Search view without rescanning
