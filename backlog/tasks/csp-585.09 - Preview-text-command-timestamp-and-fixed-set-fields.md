## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
- Why: ADR 0112 §2. The remaining field rows need previews by value type: free text and lists show their full value, command lines one argument per line, timestamps their absolute time with age, and fixed-set values (`harness`, `backend`, `provider`, `status`, `state`, `draft`, `attached`, `scope`, `capabilities`, `source`, `depth`) what they mean.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Free-text and list fields (`title`, `alias`, `name`, `reason`, `last_message_preview`, `remotes`) preview their full, untruncated value
- [ ] #2 Command fields preview the command one argument per line
- [ ] #3 Timestamp fields preview the absolute time in local time and UTC, with the age
- [ ] #4 Fixed-set fields preview a glossary entry for their value, and an unknown value says it has no entry rather than showing nothing
- [ ] #5 Fields that name a node preview that node, per ADR 0112 §2
<!-- AC:END -->

- [ ] #2 Docs and ADRs are updated when behavior, architecture, or workflow change
