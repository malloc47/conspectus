## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
- Why: ADR 0112 §2. The remaining field rows need previews by value type: free text and lists show their full value, command lines one argument per line, timestamps their absolute time with age, and fixed-set values (`harness`, `backend`, `provider`, `status`, `state`, `draft`, `attached`, `scope`, `capabilities`, `source`, `depth`) what they mean.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Free-text and list fields (`title`, `alias`, `name`, `reason`, `last_message_preview`, `remotes`) preview their full, untruncated value
- [x] #2 Command fields preview the command one argument per line
- [x] #3 Timestamp fields preview the absolute time in local time and UTC, with the age
- [x] #4 Fixed-set fields preview a glossary entry for their value, and an unknown value says it has no entry rather than showing nothing
- [x] #5 Fields that name a node preview that node, per ADR 0112 §2
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. `FieldValue` variants for text, lists, commands, timestamps, glossary values, and nodes, set where each field is built.
2. Value-only previews rendered without loading; node-valued fields resolve through `node_source`.
3. A glossary for every fixed set the explorer shows.
4. Tests for splitting, timestamps, glossary hits and misses, full text, and node-valued fields.
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
- Local time needs a time-zone database; `chrono` is built without `clock`, so the preview calls `localtime_r` through the existing `libc` dependency rather than adding a crate. Non-Unix builds show UTC and age only.
- Command strings are split with a small POSIX-style splitter (quotes and backslashes, no expansion) rather than a new dependency.
- Also typed as glossary values beyond the ADR list: `role`, `session_kind`, `harness_key`. `status` previews the meaning of `active` only when the session has a last-active time.
- A PR's `repo` field is a string, not a node, so it previews the PR like its other identity fields.
<!-- SECTION:NOTES:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Every remaining field row previews by value type: full text and lists, commands one argument per line, timestamps in local time and UTC with age, glossary entries for fixed-set values (with an explicit "no glossary entry" for unknown values), and node-valued fields as that node's preview. Verified with `just check` (unit tests for splitting, timestamps, glossary, text, and node fields) and live snapshots of a mux `last_active` and a process `command`.
