## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
- Why: the first node-specific preview the operator asked for. Selecting a session today shows the tmux pane it runs in, or nothing when it has none, while the conversation is what tells sessions apart. The embedded session viewer (ADR 0052) already renders transcripts full screen; this brings an inline version of it into the Preview area.
- Blockers: the design subtask, which decides how a node exposes its preview and what a muxed session shows by default.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Selecting an agent session shows its transcript in the Preview area, rendered by the embedded session viewer, whether or not the session is attached to a mux
- [ ] #2 A session whose transcript cannot be read shows a clear unavailable state instead of an empty pane
- [ ] #3 Reselecting a session shows turns written to its transcript since it was last previewed
- [ ] #4 Mux session nodes keep the preview the design ADR assigns them
- [ ] #5 `conspectus tui --snapshot` coverage exercises the preview for a muxed session, an un-muxed session, and an unreadable transcript
