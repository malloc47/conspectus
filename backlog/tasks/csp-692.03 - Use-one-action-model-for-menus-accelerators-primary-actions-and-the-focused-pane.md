## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The Pinned view reimplemented what the Sessions and Mux views already do: Enter on a pinned session tries to launch a mux instead of opening the session viewer, v errors on a pinned session, and the . menu offers every pin option in the Pinned view but only Unpin from the Mux or Sessions view. Accelerators also ignore the right pane's entity when it has focus. The fix is a single action model keyed on the entity, not the view.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Enter on a pinned session opens the session viewer, and v works on every session wherever it appears
- [x] #2 The . menu offers the same applicable entries for an entity in every view, including pin, edit, rename, retarget, refresh, reveal, rebuild, and unpin for pinned entities
- [x] #3 Entries with nothing meaningful to show are hidden; Show rebuild plan appears only where a plan says something (a live mux says it is running and attach is the action)
- [x] #4 With the right pane focused, ., p, Enter, and v act on the entity shown there; with the left pane focused they act on the selected row
- [x] #5 Retarget uses a searchable picker of same-kind candidates, never free text
<!-- AC:END -->

## Definition of Done
<!-- DOD:BEGIN -->
- [x] #1 `just check` passes, or `git diff --check` for docs-only changes
- [x] #2 Docs and ADRs are updated when behavior, architecture, or workflow change

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Added a single action subject (right-pane entity when focused, selected row otherwise) feeding Enter, p, v, and the . menu identically across views; pinned sessions open the viewer; meaningless entries are hidden; running muxes show a meaningful plan; Retarget is a searchable same-kind picker. Covered by parity, menu, focus, and picker tests.
