## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
After detaching from or killing a mux, the row does not become a stopped mux until the operator refreshes by hand. The earlier fix cleared the tmux listing cache and re-probed after attach, but the symptom remains, so the cause is elsewhere or the fix is not on the path the operator uses. It needs a reproduction against a real terminal session, not only unit tests.
<!-- SECTION:DESCRIPTION:END -->
