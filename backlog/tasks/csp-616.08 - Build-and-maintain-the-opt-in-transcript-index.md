## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Deferred behind CSP-616.07. Builds the persistent index that the ADR settles: off by default, enabled by config, stored where and how the ADR specifies, and kept current as transcripts are appended, rewritten, or deleted. Without this, search stays on the on-demand scan, which is correct but slows as history grows.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 With the index disabled (the default) nothing is written, which a test verifies
- [ ] #2 Enabling the index builds it with the engine, location, and permissions the ADR specifies
- [ ] #3 Appended, rewritten, and deleted transcripts are reflected in the index under the ADR freshness rules, with tests for each case
- [ ] #4 A documented command wipes the index
<!-- AC:END -->
