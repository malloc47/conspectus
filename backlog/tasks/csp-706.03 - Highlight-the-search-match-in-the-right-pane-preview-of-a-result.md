## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
In the Search view, and wherever a content-search result or active content filter row is selected in the left pane, the right pane's preview should show the match: highlight the search terms in the previewed transcript and position the preview at the matching message. Today the preview ignores the search.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 With a session or message result selected, the preview highlights the search terms using the shared match highlight style and scrolls to the matching message (the best hit for a session row, the hit's message for a message row)
- [x] #2 A pane result's preview shows the pane capture with the match highlighted at the matching line
- [x] #3 With a content filter active in Sessions, Mux, or PRs, the selected row's preview highlights the terms and shows the best hit
- [x] #4 The highlight clears when the search or filter is cleared, follows the displayed history entry when paging, and is covered by preview, snapshot, and consistency tests
<!-- AC:END -->

## Definition of Done
<!-- DOD:BEGIN -->
- [x] #1 `just check` passes, or `git diff --check` for docs-only changes
- [x] #2 Docs and ADRs are updated when behavior, architecture, or workflow change
<!-- DOD:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
The right-pane preview highlights the selected result's match and scrolls to the matching message for sessions, hit rows, panes, and filtered rows, following history paging; covered by preview unit tests.
