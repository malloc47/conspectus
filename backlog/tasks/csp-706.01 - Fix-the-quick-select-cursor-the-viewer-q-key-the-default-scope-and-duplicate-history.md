## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Arrow keys in the quick select modal stop moving the cursor after one item. In the viewer opened from a search, Esc dropping the search highlight is fine but q must leave the viewer at once. Content search should open on All. Repeating a search should not add history entries.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 In quick select, Up/Down and Ctrl-N/Ctrl-P move the cursor through every result in both scopes at any list length, with regression tests that press the keys repeatedly
- [x] #2 In the viewer, q closes it immediately even when a find or search highlight is active; Esc still drops the highlight first
- [x] #3 Content search opens on the All scope by default
- [x] #4 Running a search equal to one already in the history (same query, scope, and kinds) does not add an entry; it moves the existing one to the newest position
<!-- AC:END -->
