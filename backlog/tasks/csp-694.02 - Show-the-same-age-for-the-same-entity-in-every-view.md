## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Age currently means last activity for live rows, time since disappearance for gone ones, and blank for some kinds, with recency colors in some views only.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Each view's age is its most expected axis (last activity for sessions and muxes, updated for PRs, time since it stopped for History), and the same entity shows the same age in every view
- [x] #2 A mux's age no longer mixes in agent activity unless the audit's simplification keeps one formula for every view
- [x] #3 Missing age renders the same everywhere and recency colors apply wherever an age appears, including in snapshots
<!-- AC:END -->

## Definition of Done
<!-- DOD:BEGIN -->
- [x] #1 `just check` passes, or `git diff --check` for docs-only changes

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Age is the view's expected axis and equal for the same entity in every view; a mux uses its own activity; missing ages show a dash; recency colors apply everywhere. Covered by the age-equality invariant.
