## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
- Why: ADR 0112 §1. A pin stands in for a session, so its preview should be that session's when it has one, rather than its diagnostics.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 A pin bound to a session previews that session's transcript
- [x] #2 An unbound pin whose mux session is live previews the pane
- [x] #3 Any other pin previews its diagnostics, as today
<!-- AC:END -->

## Definition of Done
<!-- DOD:BEGIN -->
- [x] #1 `just check` passes, or `git diff --check` for docs-only changes
- [x] #2 Docs and ADRs are updated when behavior, architecture, or workflow change
<!-- DOD:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. `node_source` for pins follows the binding: Bound to the session's source, StaleMux to the mux's pane, Unbound to none.
2. Placeholder pin rows resolve through the same function.
3. A pin with no source renders its diagnostics when drilled into or under a Related row.
4. Resolver and diagnostics tests for each binding.
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
- The binding comes from `snapshot.pins`, which pin nodes are projected from; test fixtures that skip the projection still resolve.
- A bound pin honors the session preview choice, so under `session_preview = pane` it shows the pane.
<!-- SECTION:NOTES:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Pins preview through their binding: bound pins show their session's transcript, unbound pins with a live mux show its pane, and other pins show their diagnostics, from placeholder rows, drilled-into pin nodes, and Related rows alike. Verified with `just check`, resolver tests for each binding, and a live snapshot of a session's "realizes pin" row showing the session's transcript.
<!-- SECTION:FINAL_SUMMARY:END -->
