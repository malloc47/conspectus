## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
- Why: ADR 0112 §1–2. A RuntimeProcess node and every process-ID field (`pid`, `parent_pid`, `root_pane_pid`, `active_pane_pid`) should show the processes running there, which is how the operator sees what a pane or harness actually spawned.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A RuntimeProcess node previews its process tree, with each process's command and working directory
- [ ] #2 A process-ID field previews the tree rooted at that process
- [ ] #3 A process that has exited previews "no longer running"
- [ ] #4 The preview reads `/proc` only and degrades to an unavailable state where `/proc` does not exist
<!-- AC:END -->
