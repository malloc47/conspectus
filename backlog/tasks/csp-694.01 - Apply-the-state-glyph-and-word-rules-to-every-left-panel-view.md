## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Implements the operator's representation rules and fixes the audit's inconsistencies.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Attached or linked state uses a chain-link style glyph pair (linked, not linked) in the Sessions, Mux, and nested rows, and the pin marker no longer shares a glyph with any state
- [x] #2 The pin marker is symmetric everywhere: filled for a pin on a running entity, hollow for a pin on a stopped or unstarted one, including live pins in the Pinned view and pinned records in History
- [x] #3 Muxes, sessions, and PRs show state only as glyphs, with a glyph for every value including stopped mux and each PR state; Pinned and History keep status words
- [x] #4 Stopped mux reads stopped and removed worktree or repo reads removed in every view that uses words
- [x] #5 The audit's mechanical defects are fixed: truncation overflow, draft PR color in Pinned and History, content column alignment, duplicate checkout marker, unpadded session key, and unused row renderers
<!-- AC:END -->
