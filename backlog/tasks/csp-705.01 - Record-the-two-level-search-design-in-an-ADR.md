## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The redesign changes what / means and adds a content source (mux scrollback), so it needs a decision record before code.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 An ADR defines / as quick select over the current context with a Tab-widened All scope, and Ctrl+/ as content search with Current and All scopes, replacing the contents scope inside /
- [x] #2 It decides how an All-scope entity result opens (select in the left pane, switch view, or highlight along the shortest path in the right pane), what each entity kind matches on, and the key fallbacks for terminals that cannot send Ctrl+/
- [x] #3 It decides which entities have searchable content (session transcripts and mux scrollback), the deduplication rule between a mux buffer and the session shown in it, the payload and capability consequences of reading scrollback, and --no-live-preview
- [x] #4 It decides search history (how many searches, in-memory only unless the operator opts in) and how the Search view pages them, and the modal sizing rule
<!-- AC:END -->
